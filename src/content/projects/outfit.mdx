<div>
<h3>The problem</h3>
<p>I wanted to see what I actually wear, stop defaulting to the same few outfits, and get a weather-aware nudge in the morning. Existing closet apps are slow to set up, want accounts, and suggest generic outfits that ignore what you own. So I wrote a spec and directed Claude Code to build my own, over three days and 19 shipped versions.</p>
</div>
</div>

<PullQuote accentColor="#a8811f">
Nudge, don't dictate.

<div>
<h3>A rules engine, not an AI</h3>
<p>Today only gives a starter in plain words ("sweater + pants + jacket"). Real outfit ideas built from my closet show up when I ask. They come from an on-device rules engine that checks each outfit hour by hour against the forecast, scores color harmony, and learns from what I log and like. I first built a version that called Claude's API, but it cost money per use. The rules engine was good enough and free forever.</p>
</div>
</div>

<div class="single-col wide">
<h3>Built from real use</h3>
<p>Using it every day drove the roadmap. v1 worked, but I didn't want to open it, so I redesigned it as "Swiss style meets editorial." Messy photo backgrounds made the closet look chaotic, so the app now cuts each garment out onto one studio backdrop on the phone. The first model crashed my iPhone; a 4.6 MB model plus a crash guard fixed it. I change to go out at night, so a day can have multiple fits.</p>
</div>

<PullQuote accentColor="#a8811f">
A feature isn't done when it works; it's done when I want to open the app.
</PullQuote>

<div class="single-col wide">
